# Modbus TCP 配置说明

ForgeLink 的 Modbus TCP 驱动使用 NModbus 3.0.83。NModbus 负责 MBAP、事务号、功能码、异常响应及 TCP 报文处理；ForgeLink 不自行实现原生 Modbus 协议帧。

## 设备配置

| 配置 | 说明 | 默认值 |
| --- | --- | ---: |
| 协议 | 选择 `Modbus TCP` | - |
| 主机地址 | PLC、网关或 Modbus Server 的 IP/主机名 | `127.0.0.1` |
| 端口 | Modbus TCP 监听端口 | `502` |
| Unit ID | 从站地址或网关后的设备地址 | `1` |
| 连接超时 | TCP 建连最大等待时间 | `3000 ms` |
| 读取超时 | 单次 NModbus 请求最大等待时间 | `2000 ms` |

Unit ID 可以配置为 0–255。直连 PLC 常见为 1，但通过 Modbus TCP/RTU 网关时必须以现场网关配置为准。

## 点位地址

推荐使用含区域前缀的零基地址，含义明确且不受厂商手册起始编号影响：

| 格式 | 区域 | 功能码 | 示例 |
| --- | --- | ---: | --- |
| `COIL:n` | 线圈 | 01 | `COIL:0` |
| `DI:n` | 离散输入 | 02 | `DI:10` |
| `HR:n` | 保持寄存器 | 03 | `HR:0` |
| `IR:n` | 输入寄存器 | 04 | `IR:20` |

同时兼容常见五位参考地址：

```text
00001 -> COIL:0
10001 -> DI:0
30001 -> IR:0
40001 -> HR:0
```

不同厂商手册可能把寄存器编号写成零基、一起始或六位扩展格式。型号确定后，应先对照手册把地址归一化为 `HR:n` 等显式格式，不建议依赖猜测。

## 数据类型和寄存器数量

| 数据类型 | 寄存器数量 |
| --- | ---: |
| Boolean、Int16、UInt16 | 1 |
| Int32、UInt32、Float | 2 |
| Int64、Double | 4 |
| String | `ceil(StringLength / 2)` |

线圈和离散输入只允许配置为 Boolean。字符串当前按 ASCII 解码，最大 250 字节。

## 字节序和字序

- `BigEndian`：寄存器内部高字节在前；
- `LittleEndian`：寄存器内部低字节在前；
- `HighWordFirst`：多寄存器值的高字在前；
- `LowWordFirst`：多寄存器值的低字在前。

默认组合是 `BigEndian + HighWordFirst`。具体 PLC 型号确定后，必须使用已知测试值对 Float、Double、Int32 等类型做对照，不能只凭厂家系列推断。

## 批量和调度

- 相同采集时刻、相同功能区的连续地址合并为一次读取；
- 线圈/离散输入单次最多 2000 点；
- 保持/输入寄存器单次最多 125 个寄存器；
- 同一设备请求保持串行；
- 每个点位按自身 `ScanIntervalMs` 到期调度；
- 连接失败采用指数退避和随机抖动重试。

## 连接测试

- 设备存在启用点位时：建立 TCP 连接并实际读取第一个启用点位；
- 没有启用点位时：只验证 TCP 连接，并在结果中明确提示未验证 Unit ID、功能区和地址；
- 端口不可达、超时、非法地址或 Modbus 异常不会显示为成功。

## 安全边界

当前 Modbus TCP 驱动保持只读。即使点位配置了 `AllowWrite`，应用层写入白名单和二次确认尚未完成前，驱动仍会拒绝所有写请求。

本机 NModbus 从站测试只证明协议适配器和转换逻辑可运行，不等同于具体现场 PLC 型号验收。
